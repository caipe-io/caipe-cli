# Maintainers

CAIPE CLI is maintained as part of the CAIPE project. The
[project maintainer roster](https://github.com/caipe-io/ai-platform-engineering/blob/main/MAINTAINERS.md)
lists the current maintainers and their GitHub profiles.

- Use [issues](https://github.com/caipe-io/caipe-cli/issues) for CLI bugs and feature requests.
- Request maintainer review on CLI pull requests.
- Follow the [security policy](SECURITY.md) for private vulnerability reports.
- See [project governance](https://github.com/caipe-io/governance) for decision making and contributor roles.
