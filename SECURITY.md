# Security policy

CAIPE CLI follows the
[CAIPE project security policy](https://github.com/caipe-io/ai-platform-engineering/blob/main/SECURITY.md).
Use the private reporting channel listed there for suspected vulnerabilities in
the CLI, its installer, authentication, credential storage, or update mechanism.

- Do not report vulnerabilities through public issues or pull requests.
- Include the CLI version, operating system, reproduction steps, and impact.
- Remove tokens, passwords, and other credentials from logs and examples.

The project policy describes vulnerability coordination and disclosure.
